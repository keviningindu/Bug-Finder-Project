# Bug Finder Project

This project showcases the practice of **bug tracking**, issue management with **Jira**, and **UI testing** completed during the QA Engineer Bootcamp at Tripleten.

## 🚀 Features
- Bug reporting and tracking in Jira with reproducible workflows.
- Sample bug reports including clear steps, expected vs. actual results.
- User Interface (UI) tests to validate consistency and usability.
- Bilingual documentation (EN/ES) for multicultural teams.

## 🛠️ Tools & Technologies
- Jira (issue management)
- QA tools for UI testing
- GitHub for version control

## 🎯 Objective
Enhance traceability and communication in software projects through clear bug reports and structured UI testing.
